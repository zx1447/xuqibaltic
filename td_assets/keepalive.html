④ 使用说明（重要）

1. 本页必须保持标签页打开——静态页面由浏览器执行，标签页关了就没有人访问目标了。建议固定在一个单独窗口/标签。

2. 已休眠的环境无法被 ping 唤醒——先登录 trial.teradata.com → Environments 手动启动环境，等 JupyterLab 可打开后，再开启本页防止它再次闲置休眠。

3. 两种用法：
· 本地打开（本文件双击）：匿名 no-cors ping，能制造持续入站流量；
· 同源部署（推荐，真正的"自己访问自己"）：把本文件放进 Teradata 容器，通过 https://web-xxx.env.trial.teradata.com/files/keepalive.html 打开——页面与目标同源，请求自动带上 Jupyter 登录 cookie，并在 /api/status 里读到真实内核状态，保活效果最强。

4. 状态判断：失败=连接不通（环境大概率已休眠/停止）；成功=有 HTTP 响应（环境活着）。同源模式下会显示 /api/status 的 JSON 详情。
